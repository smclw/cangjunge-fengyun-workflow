# 常见问题

## 关闭浏览器会丢数据吗？

不会。项目事实源是 `data/projects/<项目ID>/project.json`。浏览器 localStorage 只保存侧栏偏好和当前项目 ID。

## 为什么比率显示“暂无数据”？

分母为 0、相关字段未知，或金额来自不同币种时，系统拒绝生成误导比率。未知应留空，已测为零才填 0。

## 为什么不能直接发布或调用 Topview？

第一阶段明确保留账号、计费、版权和发布的最后人工确认。系统产出制作包和发布草稿，不触发外部现实动作。

## 演示数字是真的吗？

不是。所有演示页面和导出都标注“演示数据，不代表真实经营结果”。

## 删除后还能找回吗？

项目删除是软删除，目录移动到 `data/backups/deleted-*`。当前界面不提供一键还原软删除，请先保留系统备份并由维护人员核对后恢复。

## 能从其他电脑迁移吗？

可以。先用设置页或 BAT 创建备份，在另一台安装 Node 22 的 Windows 电脑复制项目目录，启动后从设置页恢复 ZIP。
