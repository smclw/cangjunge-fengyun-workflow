# 使用说明

## 建议先走一遍演示项目

双击 `启动工作流.bat` 后，系统默认选择“演示-问题解决型好物视频”。仪表盘、选题、脚本、制作包、发布记录、7 天累计数据和复盘均来自该项目 JSON；这些数据仅用于验证功能，不代表真实经营结果。

## 建立真实项目

1. 打开“新建项目”，填写项目名、类型和首发平台。
2. 依次完成目标、定位、产品、素材与趋势研究 Brief。不会的字段可使用“让 AI 建议”，但建议内容仍需你核实。
3. 保存选题步骤后，服务端按 `config/scoring.json` 为每个产品生成并评分 4 个选题。
4. 保存脚本步骤后生成涨粉、成交、信任三版；每版包含 3 个钩子、口播、字幕、分镜、产品镜头、声音、CTA、禁止内容和素材清单。
5. 保存 Topview 步骤后得到可复制的中英文提示词、场景、上传顺序和检查清单。
6. 手动进入 Topview 生成视频；回到系统勾选人工任务并做质量检查。
7. 在发布计划录入草稿与披露状态，发布后补实际时间和链接。
8. 在数据分析录入发布以来的累计快照。未知字段留空，不要填 0 代替未知。
9. 在复盘中心生成诊断和下一轮实验；每轮只改变一个主要变量。

## 素材规则

单文件上限 10 MiB。支持常见图片、视频、PDF、Word、Excel、CSV、TXT 和 Markdown；脚本、HTML、SVG 和可执行文件会被拒绝。扩展名、MIME 和基础文件签名不一致也会被拒绝。上传只保存到当前项目的 `materials/`，文件名包含时间和随机段，不覆盖原文件。

## 数据快照口径

所有节点都是“发布以来累计值”。仪表盘对同一视频和平台只选 `dataThroughAt` 最新的一条，再跨视频汇总分子和分母。比率不做简单平均；分母为 0 或必需字段未知时显示“暂无数据”。

## 项目维护

- “归档”保留全部数据，可以恢复。
- “删除”要求再次确认项目全名，并把目录移动到 `data/backups/deleted-*`，不是永久擦除。
- 导出产生 20 个标准业务文件和可迁移项目 JSON。
- 系统备份 ZIP 含 `manifest.json`、文件大小与 SHA-256；设置页恢复前会先备份现状。
