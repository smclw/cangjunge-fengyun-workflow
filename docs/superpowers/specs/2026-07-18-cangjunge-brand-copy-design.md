# 沧钧阁品牌文案调整规格

## 目标

将操作台的展示品牌改为“沧钧阁”，并将工作流主标题改为“沧钧阁 · 风云化金工作流”。

## 修改范围

- 左侧栏顶部品牌由 `Topview` 改为 `沧钧阁`。
- 工作区首页及各页面共用的顶部主标题由 `Topview涨粉变现工作流` 改为 `沧钧阁 · 风云化金工作流`。
- 更新端到端测试中的主标题断言。

## 保持不变

- `Topview 制作包`、`Topview 制作`、登录 Topview 等平台功能名称保持不变，避免把第三方平台名称与自有品牌混淆。
- 项目目录、Skill 名称、API、数据 Schema、已有项目数据和导出格式保持不变。
- 浏览器标签标题不在本次两个指定界面位置的范围内。

## 验证

- 运行前端类型检查。
- 运行相关 Chrome E2E 测试，确认新品牌和新主标题可见，导航与数据不受影响。
- 检查 Git 差异，确保不包含当前运行过程中产生的项目数据变化。
