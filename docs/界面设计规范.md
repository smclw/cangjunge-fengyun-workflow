# 界面设计规范

## 参考图结论

- 画布：1672×941，固定左侧导航约 210px，内容区采用 12 列网格。
- 层级：近黑蓝页面、深蓝二级区、半透明面板；面板以 1px 冷蓝边框分隔。
- 卡片：14–18px 圆角，16–20px 内边距，关键卡片有低透明外发光。
- 色彩：背景主色接近 `#000716/#040E23/#0B132D`，主强调蓝 `#2F7BFF`，青 `#31D7E8`，紫 `#8B5CF6`，橙 `#FF9D3D`。
- 字号：页面标题 28–34px，区块 18–20px，KPI 数字 28–36px，正文 13–15px。
- 密度：首页在 900px 高度内展示主链路；小屏允许内容纵向滚动，不压缩到不可读。

## 图表契约

- 趋势图：时间至少 7 个点；同图只放同类量级，收入/订单另行切换或使用 Tooltip。
- 漏斗：按曝光到成交的有序阶段展示精确值与阶段转化率，不用面积夸大差异。
- 选题：横向评分条直接标分，颜色不是唯一状态编码。
- 所有图表标题保持描述性，副标题标明周期和“演示/真实”数据状态。
