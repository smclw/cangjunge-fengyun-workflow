# Skill 协同说明

项目专用 Skill 位于 `.agents/skills/topview-growth-monetization`，负责把同一项目事实源路由到四种模式：引导、快速、批量和复盘。`SKILL.md` 是入口，13 份 references 保存各阶段规则，scripts 负责校验/KPI/迁移/导出，assets 保存可复用模板，agents 定义 Codex 外观。

协同时每项成果只设一个主负责人：总控维护阶段和事实源；Topview 流程负责制作包；脚本写作负责口播与分镜；采集流程只记录公开来源、时间和核实状态；数据流程负责 KPI、图表和诊断。付费生成、账号登录和正式发布始终停在人工授权前。

常用触发语包括“启动涨粉变现工作流”“新建视频项目”“生成选题库”“生成三套脚本”“生成Topview制作包”“录入发布数据”“复盘这条视频”“分析为什么不成交”。详细触发与字段规则以项目 Skill 为准。
