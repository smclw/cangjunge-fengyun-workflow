# Topview 手动操作说明

第一阶段把账号登录、付费与正式生成保留为人工关卡。

1. 在系统的“Topview 制作包”选择脚本版本，复制中文或英文完整提示词。
2. 点击“打开素材文件夹”，核对你拥有或已获授权的图片、视频、Logo。
3. 手动登录 Topview，新建项目并按制作包的上传顺序加入素材。
4. 粘贴提示词与口播，检查场景规划，删除无关自动素材，替换错误产品图。
5. 核对 Logo、包装文字、产品外观、人物手部、声音、字幕、BGM 与 9:16 画幅。
6. 先生成预览，重点检查前两秒、绝对化用语、虚假实测和 AI 幻觉画面。
7. 只有在你确认计费、版权和效果后，才手动生成正式版本并下载。
8. 回到操作台勾选人工任务，在复盘中心完成质量检查；不建议发布的内容不要进入发布流程。

本系统不会替你登录、充值、调用收费 API 或发布。若以后启用 Topview API，应另行设计额度上限、凭据存储、预估费用、幂等与人工最终确认。
